# Spring Boot Project - Task 1

This is my first project using Java and Spring Boot. The application is a simple web server that uses Spring MVC and Thymeleaf to render HTML pages and serve static content.

## How it works

The application has two main endpoints:

### 1. Main Page
* **URL:** `http://localhost:8080/`
* **Description:** A simple endpoint that returns text directly to the browser.
